# Zelda: Twilight Princess — Browser Emulator

Try it in your browser: https://jolly-truth-1240.wbcb1490fan.workers.dev/

This project runs in the browser using WebGPU. Use a recent version of Chrome or Microsoft Edge; other browsers may not support it.

## ROM

You need to provide your own game ROM. No ROM files are included with this project. Only use games you have the right to use.
